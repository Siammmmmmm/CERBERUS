# Cerberus

Cerberus is a portable hardware-backed encrypted password vault built for embedded systems and security engineering exploration.

The project combines:
- Embedded firmware development
- Desktop software in C++/Qt
- Cryptography and secure storage
- Hardware security with the ATECC608A secure element
- USB/BLE device communication

## Planned Features
- AES-256 encrypted credential storage
- Qt desktop management application
- USB-C communication
- Hardware-backed key protection
- Battery-powered portable design
- BLE/mobile support
- USB HID auto-fill

## Tech Stack
- C / C++
- Qt6
- ESP32-S3
- Arduino / ESP-IDF
- FreeRTOS
- mbedTLS
